# Aturan Pengembangan SiKarir Mobile

## Panduan Pembuatan Pull Request (PR)
Setiap kali diminta membuat Pull Request (PR):
1. **Link PR**: Selalu sediakan link langsung untuk membuat PR di GitHub.
2. **Ringkasan Perubahan**:
   - Judul PR (`Title`) yang jelas, rapi, dan mengikuti konvensi (misal: `feat: ...`, `fix: ...`).
   - Deskripsi PR (`Description`) terstruktur rapi:
     - 📋 Ringkasan Perubahan
     - 🚀 Detail Pembaruan (per layer: Data/Model, Service & Repo, Provider/State, UI/Presentation)
3. **End-to-End (E2E) Test / Skenario Pengujian**:
   - Selalu sertakan skenario pengujian End-to-End (langkah uji coba dari awal sampai akhir beserta hasil yang diharapkan).
   - Sertakan checklist verifikasi fungsional untuk memastikan fitur bekerja sesuai harapan pengguna.
